# Agent Rules (Sample)

These are the project rules for AI agents working in this repository.

## Rules

- Never force push to the main branch
- Always run tests before committing (`npm test`)
- Use pnpm as the package manager
- Write clean, maintainable code following best practices
- Never delete files in the `data/` directory

## Guidelines

- Consider refactoring when functions grow too long
- Try to keep PRs focused on a single change

## Notes

These rules are advisory unless enforced by hooks or CI checks.
