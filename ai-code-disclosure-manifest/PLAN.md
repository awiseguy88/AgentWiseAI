# Build Plan: AI Code Disclosure Manifest

## Goal
Build a dependency-free CLI tool that scans a git repository for AI-assist markers in commits and source files, classifies findings with confidence levels, and generates an offline HTML/JSON disclosure manifest plus copyable notice templates (disclosure, attribution, CC0/OSS).

## User-Facing Behavior
- **CLI entry point**: `ai-disclose` (or `ai-code-disclosure`)
- **Basic usage**: `ai-disclose scan [repo-path]` — scans current dir or given path
- **Output modes**: 
  - `json` — machine-readable manifest
  - `html` — offline human-readable report (self-contained, no external assets)
  - `templates` — prints disclosure/attribution/CC0 notice snippets to stdout
- **Flags**:
  - `--format json|html|templates` (default: html)
  - `--output <file>` (default: stdout for json/templates, `disclosure-manifest.html` for html)
  - `--confidence high|medium|low|all` (default: all)
  - `--since <date>` — limit scan to commits after date
  - `--verbose` — detailed progress

## Marker Patterns to Detect

### Git Commit Trailers
- `Co-Authored-By: <name> <email>` where email matches known AI agents (e.g., `*.users.noreply.github.com` with bot-like names)
- `Generated-By: <tool>` / `AI-Generated: true` / `Agent: <name>`
- `Signed-off-by:` with AI-associated identities

### Commit Message Patterns
- "Generated by <tool>", "Created with <tool>", "AI-assisted", "Co-authored by <bot>"
- Common copilot/agent signatures: GitHub Copilot, Cursor, Claude Code, DeepSeek, etc.

### Source File Markers
- Header comments: `// Generated by <tool>`, `/* AI-generated */`, `# -*- coding: utf-8 -*- # Generated by`
- Inline comments: `// AI:`, `// TODO(AI):`, `// Copilot:`, `// Claude:`
- Prompt-like comments: `// Prompt:`, `/* prompt: */`
- Tool-specific markers: `/// <reference path="..." />` with AI tool paths

### Confidence Classification
| Confidence | Criteria |
|------------|----------|
| **High** | Explicit trailer (`Generated-By`, `AI-Generated`), known bot co-author email, generated header with tool name |
| **Medium** | AI-related keywords in commit message, prompt-like comments, tool signatures in comments |
| **Low** | Generic "AI" or "generated" mentions without tool attribution, ambiguous patterns |

## Test Strategy
1. **Fixtures**: Create 2-3 mini git repos in `test/fixtures/` with:
   - Known AI markers (trailers, headers, comments)
   - Clean files (no markers)
   - Mixed commits
2. **Smoke test**: Run `ai-disclose scan` on fixture, verify:
   - Outputs valid JSON with expected structure
   - HTML output is self-contained (no external deps)
   - Templates output contains all three notice types
   - Classification counts match seeded markers
3. **Unit tests**: Test `classify.js` functions directly with various input strings
