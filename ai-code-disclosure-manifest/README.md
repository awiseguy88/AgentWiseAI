# AI Code Disclosure Manifest

An offline-first, dependency-free CLI tool that scans Git repositories for AI-assist markers in commit history and source files, classifies findings with confidence levels, and generates disclosure manifests plus copyable notice templates (disclosure, attribution, CC0, OSS).

## Why This Tool

As AI-generated code becomes common, teams face confusion about attribution, disclosure, and whether AI-assisted output should be treated as open or proprietary — creating legal and trust risk in shared codebases. This tool replaces manual git-history audits and ad-hoc commit-message checks with an automated, offline scan that produces a clear, verifiable report.

## Features

- **Zero dependencies** — runs on Node.js stdlib only, no network access required
- **Git history scan** — detects AI markers in commit trailers (`Co-Authored-By`, `Generated-By`), messages, and signatures
- **Source file scan** — finds generated headers, prompt comments, tool signatures in code files
- **Confidence classification** — High / Medium / Low based on marker specificity
- **Multiple output formats**:
  - `json` — machine-readable manifest for CI/CD integration
  - `html` — self-contained offline report with interactive templates
  - `templates` — plain-text disclosure, attribution, CC0, and OSS notices
- **Notice templates** — ready-to-copy Disclosure, Attribution, CC0 Dedication, and OSS Notice

## Quick Start

```bash
# Scan current repository, output HTML report
ai-disclose scan

# Scan specific path, output JSON to stdout
ai-disclose scan ./my-project -f json

# Scan with only high-confidence findings, save HTML
ai-disclose scan --confidence high -f html -o report.html

# Quick scan (git history only, no file walk)
ai-disclose quick

# Generate notice templates only
ai-disclose templates

# Show help
ai-disclose --help
```

## Usage

```
ai-disclose <command> [path] [options]

Commands:
  scan        Full scan: git history + source files (default)
  quick       Quick scan: git history only (faster)
  templates   Generate notice templates from scan

Options:
  -f, --format <format>     Output format: json, html, templates (default: html)
  -o, --output <file>       Output file (default: stdout for json/templates, disclosure-manifest.html for html)
  -c, --confidence <level>  Minimum confidence: high, medium, low, all (default: all)
  -s, --since <date>        Only scan commits after ISO date (e.g., 2024-01-01)
  -q, --quick               Quick mode: git history only, no file scan
  -v, --verbose             Verbose progress output
  -h, --help                Show help
```

## Detected Marker Patterns

| Category | Patterns | Confidence |
|----------|----------|------------|
| **Commit Trailers** | `Generated-By:`, `AI-Generated:`, `Agent:`, `Co-Authored-By:` (bot emails) | High |
| **Commit Messages** | "Generated by Copilot", "Created with Claude", "AI-assisted", "Co-authored by Cursor" | High/Medium |
| **File Headers** | `// Generated by <tool>`, `/* AI-generated */`, `# Generated by`, `@generated` | High/Medium |
| **Inline Comments** | `// AI:`, `// Copilot:`, `// Prompt:`, `// TODO(AI):` | Medium/Low |
| **Keywords** | `ai`, `gpt`, `llm`, `automated`, `copilot`, `claude`, `deepseek`, `cursor` | Low |

## Confidence Levels

| Level | Criteria |
|-------|----------|
| **High** | Explicit trailer (`Generated-By`, `AI-Generated`), known bot co-author email, generated header with tool name |
| **Medium** | AI-related keywords in commit message, prompt-like comments, tool signatures in comments |
| **Low** | Generic "AI" or "generated" mentions without tool attribution, ambiguous patterns |

## Integration

### CI/CD (GitHub Actions)

```yaml
- name: AI Disclosure Scan
  run: |
    npx ai-code-disclosure-manifest scan -f json -o disclosure.json
    # Parse JSON for gates, upload as artifact, etc.
```

### Pre-commit Hook

```bash
#!/bin/sh
# .git/hooks/pre-commit
ai-disclose scan --confidence high -f json -o /tmp/disclosure.json
# Check for new high-confidence findings
```
